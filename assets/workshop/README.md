# Workshop runtime assets

These PNGs are optimized runtime exports from `assets_source/workshop/`.

- `background.png`: clean 1280x720 shop plate.
- `station_bases.png`: all static production stations on transparency.
- `customer_counter.png`: counter foreground on transparency.
- `masks/`: station-local interaction silhouettes.
- Furnace and quench are intentionally rendered from the static station layer. Their experimental animation frames remain only in `assets_source/` and are not packaged as runtime art.
- `assets/characters/blacksmith_idle/`: four-frame sparse hammer idle used in the open shop floor.
- `assets/characters/customer_idle/`: three-frame customer idle drawn behind the counter foreground.

Editable full-resolution sources and layout coordinates are retained in `assets_source/`. There is no customer walking/entrance sequence in this asset set.
